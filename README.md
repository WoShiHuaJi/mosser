# mosser 礼盒订单管理系统

纯前端礼盒订单管理工具，无需后端服务器，数据保存在本地文件夹中。

## 功能

- **库存缺口统计**（首页）：汇总待备货订单的产品需求，对比库存显示缺口
- **订单管理**：订单状态流转（待备货 → 已备货 → 已发货 → 已完成）
  - 确认备货自动扣减库存，取消备货回滚库存
  - 从礼盒模板一键填充产品（支持输入礼盒数量）
  - 收款状态标记、备注、金额统计
- **产品库**：产品名称、单位、单价、库存管理
- **礼盒模板**：预设礼盒内含产品组合
- **客户管理**：客户信息维护
- **送货清单**：生成送货单，支持打印与导出 PDF
- **数据导入/导出**：JSON 格式全量备份与恢复

## 技术栈

- Vue 3 + Vite
- Element Plus
- vue-router（hash 模式）
- vuedraggable / xlsx / jspdf + html2canvas

## 数据存储

使用浏览器 File System Access API，首次使用需选择一个本地文件夹：

```
<选择的文件夹>/
├── data.json                      # 全量业务数据
└── backups/
    └── backup-YYYY-MM-DD.json     # 每日自动备份（保留当天最初状态）
```

- 数据变更后 500ms 防抖自动保存
- 目录句柄存于 IndexedDB，下次打开自动恢复
- 推荐使用 Chrome / Edge 浏览器

## 开发

```bash
cd 管理系统
npm install
npm run dev
```

## 构建

```bash
npm run build
```

产物输出到 `管理系统/dist/`，部署到任意静态服务器即可。
